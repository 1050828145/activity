# 活动参与人员清单导出格式功能说明

## 更新概述

为活动参与人员清单导出功能提供两种导出格式选项：单Sheet格式（所有活动合并在一个Sheet中，增加活动名称列）和多Sheet格式（每个活动一个Sheet），满足不同的数据查看和处理需求。

## 一、功能说明

### 1.1 导出格式定义

**导出格式**：用户可以选择将参与人员数据导出为单Sheet格式或多Sheet格式。

**格式类型**：
1. **单Sheet格式**：所有活动的参与人员合并在一个Sheet中，增加"活动名称"列
2. **多Sheet格式**：每个活动一个Sheet，Sheet名称为活动名称（原有格式）

**默认格式**：多Sheet格式

### 1.2 单Sheet格式

**特点**：
- 所有活动的参与人员数据合并在一个Sheet中
- 增加"活动名称"列，标识每个参与人员所属的活动
- Sheet名称固定为"参与人员清单"
- 便于跨活动数据对比和统计

**列结构**：
```
序号 | 活动名称 | 姓名 | 电话 | 介绍人 | ... (其他选中的字段)
```

**适用场景**：
- 需要跨活动对比数据
- 需要统计多个活动的总体情况
- 需要在一个表格中查看所有数据
- 需要使用Excel的筛选、排序等功能处理数据

### 1.3 多Sheet格式

**特点**：
- 每个活动一个独立的Sheet
- Sheet名称为活动名称
- 每个Sheet只包含该活动的参与人员数据
- 便于按活动查看和管理数据

**列结构**：
```
序号 | 姓名 | 电话 | 介绍人 | ... (其他选中的字段)
```

**适用场景**：
- 需要按活动分别查看数据
- 需要将不同活动的数据分发给不同的人
- 需要保持活动数据的独立性
- 需要打印或分享单个活动的数据

## 四、技术实现

### 4.1 状态管理

```typescript
// 导出格式状态
const [exportFormat, setExportFormat] = useState<'single' | 'multiple'>('multiple');
```

**说明**：
- `exportFormat`：导出格式，'single'表示单Sheet格式，'multiple'表示多Sheet格式
- 默认值：'multiple'（多Sheet格式）

### 4.2 单Sheet格式实现

```typescript
if (exportFormat === 'single') {
  // 单Sheet格式：所有活动的参与人员放在一个sheet中
  const allParticipants: any[] = [];
  
  for (const activityId of selectedIds) {
    const activity = activities.find(a => a.id === activityId);
    if (!activity) continue;

    // 获取该活动的参与人员详情
    let participants = await getActivityParticipantsWithDetails(activityId);
    
    // 应用筛选条件
    if (filterStatus.length > 0) {
      participants = participants.filter(p => filterStatus.includes(p.status));
    }
    
    if (filterIsPaid !== 'all') {
      const isPaidValue = filterIsPaid === 'true';
      participants = participants.filter(p => p.is_paid === isPaidValue);
    }

    // 为每个参与人员添加活动信息
    participants.forEach(p => {
      allParticipants.push({
        activity: activity,
        participant: p
      });
    });
  }

  // 准备sheet数据（添加序号和活动名称）
  const sheetData = allParticipants.map((item, index) => {
    const row: any = { 
      '序号': index + 1,
      '活动名称': item.activity.name
    };
    selectedColumns.forEach(col => {
      row[col.customHeader || col.defaultHeader] = col.getValue(item.participant);
    });
    return row;
  });

  // 创建worksheet并应用样式
  const worksheet = XLSX.utils.json_to_sheet(sheetData);
  // ... 样式设置代码

  // 设置列宽（序号列固定8，活动名称列20，其他列自适应）
  worksheet['!cols'] = [
    { wch: 8 }, // 序号列
    { wch: 20 }, // 活动名称列
    ...selectedColumns.map(col => ({
      wch: Math.max((col.customHeader || col.defaultHeader).length * 2, 15)
    }))
  ];

  XLSX.utils.book_append_sheet(workbook, worksheet, '参与人员清单');
}
```

**关键点**：
1. 遍历所有选中的活动
2. 获取每个活动的参与人员并应用筛选条件
3. 将所有参与人员合并到一个数组中，同时保存活动信息
4. 生成sheet数据时，添加"活动名称"列
5. 设置活动名称列的列宽为20
6. Sheet名称固定为"参与人员清单"

### 4.3 多Sheet格式实现

```typescript
else {
  // 多Sheet格式：每个活动一个sheet（原有格式）
  for (const activityId of selectedIds) {
    const activity = activities.find(a => a.id === activityId);
    if (!activity) continue;

    // 获取该活动的参与人员详情
    let participants = await getActivityParticipantsWithDetails(activityId);
    
    // 应用筛选条件
    if (filterStatus.length > 0) {
      participants = participants.filter(p => filterStatus.includes(p.status));
    }
    
    if (filterIsPaid !== 'all') {
      const isPaidValue = filterIsPaid === 'true';
      participants = participants.filter(p => p.is_paid === isPaidValue);
    }

    // 准备sheet数据（添加序号）
    const sheetData = participants.map((p, index) => {
      const row: any = { '序号': index + 1 };
      selectedColumns.forEach(col => {
        row[col.customHeader || col.defaultHeader] = col.getValue(p);
      });
      return row;
    });

    // 创建worksheet并应用样式
    const worksheet = XLSX.utils.json_to_sheet(sheetData);
    // ... 样式设置代码

    // 使用活动名称作为sheet名称
    let sheetName = activity.name;
    if (sheetName.length > 31) {
      sheetName = sheetName.substring(0, 28) + '...';
    }
    sheetName = sheetName.replace(/[:\\\/\?\*\[\]]/g, '_');

    // 处理sheet名称重复
    let finalSheetName = sheetName;
    let counter = 1;
    while (workbook.SheetNames.includes(finalSheetName)) {
      const suffix = ` (${counter})`;
      finalSheetName = sheetName.substring(0, 31 - suffix.length) + suffix;
      counter++;
    }

    XLSX.utils.book_append_sheet(workbook, worksheet, finalSheetName);
  }
}
```

**关键点**：
1. 遍历所有选中的活动
2. 为每个活动创建一个独立的Sheet
3. 获取参与人员并应用筛选条件
4. 生成sheet数据时，不添加"活动名称"列
5. 使用活动名称作为Sheet名称
6. 处理Sheet名称长度限制和重复问题

### 4.4 样式应用

两种格式都使用相同的样式设置：
- 表头：白色粗体文字、蓝色背景、居中对齐、黑色边框
- 数据行：序号列居中、其他列左对齐、灰色边框
- 斑马纹：偶数行浅灰色背景
- 列宽：序号列固定8，活动名称列（单Sheet格式）固定20，其他列自适应

## 七、常见问题

### Q1: 两种格式有什么区别？
**A**: 
- 单Sheet格式：所有活动合并在一个Sheet中，增加"活动名称"列
- 多Sheet格式：每个活动一个Sheet，Sheet名称为活动名称

### Q2: 默认使用哪种格式？
**A**: 
- 默认使用多Sheet格式
- 可以在导出配置对话框中切换

### Q3: 单Sheet格式的"活动名称"列可以自定义吗？
**A**: 
- 当前版本不支持自定义
- 列名固定为"活动名称"
- 列宽固定为20个字符

### Q4: 多Sheet格式的Sheet名称可以自定义吗？
**A**: 
- 不可以自定义
- Sheet名称自动使用活动名称
- 如果活动名称过长，会自动截断

### Q5: 单Sheet格式的数据顺序是怎样的？
**A**: 
- 按照选中活动的顺序
- 每个活动的参与人员按照数据库查询顺序
- 序号从1开始连续编号

### Q6: 多Sheet格式的Sheet顺序是怎样的？
**A**: 
- 按照选中活动的顺序
- 第一个选中的活动是第一个Sheet
- 依此类推

### Q7: 如果活动名称重复，Sheet名称会怎样？
**A**: 
- 系统会自动处理重复问题
- 第一个活动使用原名称
- 后续重复的活动会添加后缀 (1)、(2) 等

### Q8: 单Sheet格式和多Sheet格式的样式一样吗？
**A**: 
- 样式完全一样
- 都使用蓝色表头、斑马纹数据行
- 都有边框和对齐设置

### Q9: 筛选条件对两种格式都有效吗？
**A**: 
- 是的，筛选条件对两种格式都有效
- 筛选逻辑完全相同
- 只是数据的组织方式不同

### Q10: 可以同时导出两种格式吗？
**A**: 
- 当前版本不支持
- 每次只能选择一种格式
- 如果需要两种格式，需要导出两次
