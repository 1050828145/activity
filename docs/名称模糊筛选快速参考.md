# 名称模糊筛选 - 快速参考指南

## 核心功能

### 模糊筛选定义
**输入部分关键词，自动匹配包含该关键词的所有记录**

### 特点
- ✅ 不区分大小写
- ✅ 支持部分匹配
- ✅ 实时筛选
- ✅ 支持组合筛选

## 涉及页面

| 页面 | 筛选字段 | 状态 |
|------|---------|------|
| 活动管理 | 活动名称 | ✅ 新增 |
| 人员管理 | 姓名 | ✅ 新增 |
| 领队管理 | 姓名 | ✅ 已有 |
| 参与人员管理 | 人员姓名、活动名称 | ✅ 已有 |

## 使用方法

### 活动管理
```
1. 点击"筛选"按钮
2. 在"活动名称"输入框输入关键词
3. 自动显示匹配结果
```

### 人员管理
```
1. 点击"筛选"按钮
2. 在"姓名"输入框输入关键词
3. 自动显示匹配结果
```

### 领队管理
```
1. 点击"筛选"按钮
2. 在"姓名"输入框输入关键词
3. 自动显示匹配结果
```

### 参与人员管理
```
1. 点击"筛选"按钮
2. 在"人员姓名"或"活动名称"输入框输入关键词
3. 自动显示匹配结果
```

## 常见问题

### Q: 区分大小写吗？
**A**: 不区分（除领队管理外）

### Q: 需要输入完整名称吗？
**A**: 不需要，输入部分关键词即可

### Q: 能组合其他条件吗？
**A**: 可以，支持多条件组合

### Q: 如何清除筛选？
**A**: 点击"清除筛选"或删除输入文字

### Q: 是否实时筛选？
**A**: 是的，输入即筛选

## 使用技巧

### 技巧1：输入关键词
```
输入最具代表性的关键词
关键词越短，匹配结果越多
```

### 技巧2：逐步缩小
```
先输入大范围关键词
根据结果添加其他条件
精确定位目标数据
```

### 技巧3：组合筛选
```
先名称筛选缩小范围
再其他条件精确定位
提高筛选效率
```
