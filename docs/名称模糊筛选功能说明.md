# 名称模糊筛选功能说明

## 更新概述

为系统中所有有名称字段的表格筛选功能增加名称模糊筛选，提升数据查找效率和用户体验。

## 一、功能说明

### 1.1 模糊筛选定义

**模糊筛选**：用户输入部分关键词，系统自动匹配包含该关键词的所有记录。

**匹配规则**：
- 不区分大小写
- 支持部分匹配
- 支持中文、英文、数字
- 实时筛选，无需点击搜索按钮

### 1.2 实现效果

#### 示例1：活动名称筛选
```
输入："年会"
匹配结果：
- "2026年会活动"
- "公司年会"
- "年会筹备"
```

#### 示例2：人员姓名筛选
```
输入："张"
匹配结果：
- "张三"
- "张小明"
- "小张"
```

#### 示例3：领队姓名筛选
```
输入："王"
匹配结果：
- "王领队"
- "王经理"
- "小王"
```

### 1.3 涉及的页面

| 页面 | 筛选字段 | 状态 | 说明 |
|------|---------|------|------|
| 活动管理 | 活动名称 | ✅ 新增 | 支持模糊匹配活动名称 |
| 人员管理 | 姓名 | ✅ 新增 | 支持模糊匹配人员姓名 |
| 领队管理 | 姓名 | ✅ 已有 | 已支持模糊匹配领队姓名 |
| 参与人员管理 | 人员姓名、活动名称 | ✅ 已有 | 已支持模糊匹配 |

## 二、活动管理页面

### 2.1 新增功能

**筛选字段**：活动名称

**位置**：筛选弹窗的第一个筛选项

**UI组件**：文本输入框

**占位符文本**："输入活动名称搜索..."

### 2.2 筛选逻辑

```typescript
// 活动名称筛选（模糊匹配）
if (filterName) {
  filtered = filtered.filter(a => 
    a.name.toLowerCase().includes(filterName.toLowerCase())
  );
}
```

**说明**：
- 将活动名称和输入关键词都转换为小写
- 使用`includes`方法进行部分匹配
- 不区分大小写

### 2.3 筛选组合

活动名称筛选可以与其他筛选条件组合使用：
- 活动名称 + 活动状态
- 活动名称 + 开始日期
- 活动名称 + 结束日期
- 活动名称 + 即将进行
- 活动名称 + 即将结束

### 2.4 使用场景

#### 场景1：快速查找特定活动
```
需求：查找"年会"相关的活动
操作：在活动名称输入框输入"年会"
结果：显示所有名称包含"年会"的活动
```

#### 场景2：查找特定类型活动
```
需求：查找所有"团建"活动
操作：在活动名称输入框输入"团建"
结果：显示所有名称包含"团建"的活动
```

#### 场景3：组合筛选
```
需求：查找"年会"相关且状态为"已确认"的活动
操作：
1. 在活动名称输入框输入"年会"
2. 在活动状态下拉框选择"已确认"
结果：显示符合两个条件的活动
```

## 九、常见问题

### Q1: 为什么要添加名称筛选？
**A**: 
- 提高数据查找效率
- 减少翻页查找时间
- 符合用户使用习惯
- 提升用户体验

### Q2: 名称筛选是否区分大小写？
**A**: 
- 活动管理：不区分大小写
- 人员管理：不区分大小写
- 领队管理：区分大小写（已有功能）
- 参与人员管理：不区分大小写

### Q3: 能否搜索名称的一部分？
**A**: 
- 可以，支持部分匹配
- 输入任意部分关键词即可
- 无需输入完整名称

### Q4: 名称筛选能否与其他条件组合？
**A**: 
- 可以，支持多条件组合
- 所有筛选条件都可以组合使用
- 组合关系为逻辑与（AND）

### Q5: 如何清除名称筛选？
**A**: 
- 方法1：点击"清除筛选"按钮
- 方法2：手动删除输入框中的文字
- 方法3：刷新页面

### Q6: 名称筛选是否支持正则表达式？
**A**: 
- 当前版本不支持
- 使用简单的部分匹配
- 未来可以考虑添加高级搜索

### Q7: 名称筛选是否支持多个关键词？
**A**: 
- 当前版本不支持
- 只能输入一个关键词
- 未来可以考虑添加多关键词搜索

### Q8: 名称筛选的性能如何？
**A**: 
- 前端筛选，性能优秀
- 实时响应，无延迟
- 数据量大时可能略有延迟

### Q9: 名称筛选是否会保存？
**A**: 
- 筛选条件保存在URL参数中
- 刷新页面后筛选条件保留
- 关闭页面后筛选条件清除

### Q10: 能否自定义筛选规则？
**A**: 
- 当前版本不支持
- 使用统一的模糊匹配规则
- 未来可以考虑添加自定义选项
