# 领队招募分析 - 功能说明

## 新增功能

### 1. 领队选择功能

**功能描述：**
- 可以选择特定的领队进行分析，而不是只能查看所有领队的数据
- 支持多选和全选/取消全选
- 实时更新统计数据和图表

**使用方法：**
1. 点击页面右上角的"选择领队"按钮
2. 在弹出的面板中勾选或取消勾选领队
3. 可以点击"全选"或"取消全选"快速操作
4. 点击"确认"按钮应用选择并更新数据（或点击"取消"放弃修改）
5. 确认后，统计数据和图表会自动更新
6. 按钮上会显示当前选中的领队数量

**交互优化：**
- 勾选领队时不会立即触发数据更新，避免频繁加载
- 只有点击"确认"按钮后才会更新统计数据
- 点击"取消"按钮可以放弃本次修改，恢复到之前的选择
- 未选择任何领队时，"确认"按钮会被禁用

**应用场景：**
- 对比特定几个领队的招募情况
- 排除某些领队单独分析其他领队
- 查看单个领队的详细数据

### 2. 导出PDF功能

**功能描述：**
- 将当前的统计分析报告导出为PDF文件
- 包含所有统计卡片、图表和领队列表
- 自动分页处理长内容

**使用方法：**
1. 选择要分析的领队（可选，默认全选）
2. 点击页面右上角的"导出PDF"按钮
3. 等待PDF生成（会显示"导出中..."提示）
4. PDF生成完成后会自动下载

**导出内容包括：**
- 统计卡片：活跃领队数、总招募人数、总活动数、平均出勤率
- 领队招募人数对比图（柱状图）
- 活动类型分布图（饼图）
- 领队招募详情表格

**文件命名：**
- 格式：`领队招募分析_YYYY/M/D.pdf`
- 示例：`领队招募分析_2026/1/29.pdf`

**注意事项：**
- 如果没有选择任何领队，导出按钮会被禁用
- 导出过程中请勿关闭页面
- 如果内容较多，生成时间可能较长，请耐心等待
- 如果浏览器阻止下载，请检查浏览器设置并允许下载

## 技术实现

### 依赖库
- **jsPDF**: PDF生成库
- **html2canvas**: 将HTML内容转换为图片

### 实现原理
1. 使用 `useRef` 标记需要导出的内容区域
2. 使用 `html2canvas` 将内容转换为高清图片（scale=2）
3. 使用 `jsPDF` 创建PDF文档并添加图片
4. 自动处理分页（内容超过一页时）
5. 保存PDF文件到本地

### 领队筛选逻辑
1. 页面加载时获取所有领队列表
2. 默认选中所有领队
3. 用户更改选择时，重新加载统计数据
4. 只显示选中领队的数据

## 使用示例

### 场景1：对比两个领队的招募情况
1. 点击"选择领队"按钮
2. 点击"取消全选"
3. 只勾选需要对比的两个领队
4. 查看更新后的统计数据和图表
5. 点击"导出PDF"保存报告

### 场景2：生成月度招募报告
1. 确保所有领队都被选中（默认状态）
2. 查看整体统计数据
3. 点击"导出PDF"
4. 将生成的PDF作为月度报告存档或分享

### 场景3：分析特定领队的表现
1. 点击"选择领队"
2. 点击"取消全选"
3. 只选择一个领队
4. 查看该领队的详细数据
5. 点击表格中的"查看详情"查看更多信息
6. 导出PDF作为该领队的个人报告

## 常见问题

### Q: 为什么导出按钮是灰色的？
A: 可能是因为没有选择任何领队。请至少选择一个领队后再导出。

### Q: PDF导出失败怎么办？
A: 
1. 检查浏览器是否阻止了下载
2. 尝试减少选择的领队数量
3. 刷新页面后重试
4. 如果问题持续，请联系技术支持

### Q: 导出的PDF不清晰怎么办？
A: 系统已使用2倍缩放确保清晰度。如果仍不满意，可以：
1. 使用更大的显示器或调整浏览器缩放
2. 联系技术支持调整导出参数

### Q: 可以导出Excel格式吗？
A: 当前版本只支持PDF导出。如需Excel格式，请联系技术支持。

### Q: 选择领队后数据没有更新？
A: 请稍等片刻，系统正在加载数据。如果长时间没有响应，请刷新页面。
