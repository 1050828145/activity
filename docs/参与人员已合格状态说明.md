# 参与人员状态新增"已合格"选项

## 更新概述

在参与人员的状态选项中新增"已合格"状态，位于"已出席"之后，用于标记已出席且符合发薪条件的人员。

## 状态说明

### 完整状态列表

参与人员状态按照业务流程顺序排列：

1. **待确认**：人员已报名，等待确认
2. **已确认**：人员报名已确认，等待活动开始
3. **已出席**：人员已参加活动
4. **已合格**：人员已出席且符合发薪条件（新增）
5. **未出席**：人员未参加活动
6. **已取消**：人员取消参与

### "已合格"状态详解

**含义**：
- 人员已经出席了活动
- 经过考核/评估，符合发薪标准
- 可以正常领取工资

**使用场景**：
- 活动结束后，对出席人员进行考核
- 考核通过的人员标记为"已合格"
- 作为发薪的依据

**与"已出席"的区别**：
- **已出席**：仅表示人员到场参加了活动
- **已合格**：不仅出席，还通过了考核，可以拿工资

**状态流转**：
```
待确认 → 已确认 → 已出席 → 已合格 ✓ (正常流程)
                    ↓
                  未出席 ✗ (未到场)
```

## 视觉设计

### 状态颜色

- **待确认**：灰色（bg-muted）- 中性色，表示待处理
- **已确认**：蓝色（bg-primary）- 主色调，表示已确认
- **已出席**：绿色（bg-chart-2）- 积极色，表示已参加
- **已合格**：青色（bg-chart-1）- 积极色，表示合格通过
- **未出席**：红色（bg-destructive）- 警告色，表示未到场
- **已取消**：红色（bg-destructive）- 警告色，表示已取消

### 颜色选择理由

**为什么"已合格"使用青色（bg-chart-1）？**
1. 与"已出席"的绿色区分开
2. 青色同样是积极的颜色，表示正面结果
3. 视觉上更加醒目，便于识别
4. 符合"合格通过"的语义

## 使用方法

### 单个修改状态

**方法1：在参与人员管理页面**
1. 进入"参与记录"页面
2. 找到目标人员，点击"编辑"按钮
3. 在"参与状态"下拉框中选择"已合格"
4. 点击"保存"

**方法2：在活动详情页面**
1. 进入活动详情页面
2. 在参与人员列表中找到目标人员
3. 点击人员行的"编辑"按钮
4. 在"参与状态"下拉框中选择"已合格"
5. 点击"保存"

### 批量修改状态

1. 进入"参与记录"页面
2. 勾选需要修改的人员（可多选）
3. 点击"批量修改状态"按钮
4. 在弹出的对话框中选择"已合格"
5. 点击"确认修改"

### 筛选"已合格"人员

1. 进入"参与记录"页面
2. 点击"筛选"按钮
3. 在"参与状态"下拉框中选择"已合格"
4. 查看筛选结果

### 导入时设置状态

在批量导入人员时，可以在Excel中的"参与状态"列填写"已合格"，系统会自动识别并设置。

## 实际应用场景

### 场景1：活动结束后的考核

**背景**：某培训活动结束，需要对出席人员进行考核

**流程**：
1. 活动进行中，将到场人员标记为"已出席"
2. 活动结束后，进行考核或评估
3. 考核通过的人员，修改状态为"已合格"
4. 考核未通过的人员，保持"已出席"状态或改为其他状态

**结果**：
- 清晰区分出席和合格
- 便于后续发薪处理
- 有据可查

### 场景2：分阶段发薪管理

**背景**：活动工资分两次发放，第一次发给所有出席人员，第二次只发给合格人员

**流程**：
1. 第一次发薪：筛选"已出席"和"已合格"状态的人员
2. 发薪后，标记为"已发薪"
3. 第二次发薪：只筛选"已合格"状态的人员
4. 发放额外奖金或补贴

**结果**：
- 灵活的发薪管理
- 激励机制明确
- 财务记录清晰

### 场景3：绩效统计分析

**背景**：统计各领队招募人员的合格率

**流程**：
1. 筛选某领队招募的所有人员
2. 统计"已出席"人员数量
3. 统计"已合格"人员数量
4. 计算合格率 = 已合格 / 已出席

**结果**：
- 评估领队招募质量
- 作为绩效考核依据
- 优化招募策略

### 场景4：活动质量评估

**背景**：评估活动的整体质量和参与效果

**流程**：
1. 统计活动的报名人数
2. 统计"已出席"人数，计算出席率
3. 统计"已合格"人数，计算合格率
4. 分析活动质量

**结果**：
- 全面的活动数据
- 发现问题和改进点
- 提升活动质量

### 场景5：工资发放审核

**背景**：财务部门需要审核工资发放名单

**流程**：
1. 筛选"已合格"状态的人员
2. 导出Excel表格
3. 财务审核名单
4. 批量标记为"已发薪"

**结果**：
- 规范的发薪流程
- 减少发薪错误
- 便于财务对账

## 注意事项

### 状态设置建议

1. **按顺序设置**
   - 先设置"已出席"
   - 考核后再设置"已合格"
   - 避免跳过"已出席"直接设置"已合格"

2. **考核标准明确**
   - 制定清晰的合格标准
   - 统一考核流程
   - 确保公平公正

3. **及时更新状态**
   - 活动结束后尽快考核
   - 及时更新状态
   - 避免遗漏

### 数据统计注意

1. **合格率计算**
   - 合格率 = 已合格人数 / 已出席人数
   - 不包括"未出席"和"已取消"
   - 注意分母不为0

2. **发薪统计**
   - 可以只统计"已合格"人员
   - 也可以统计"已出席"+"已合格"
   - 根据实际业务需求选择

3. **绩效评估**
   - 综合考虑出席率和合格率
   - 不要只看单一指标
   - 结合活动类型分析

## 常见问题

### Q1: "已合格"和"已出席"有什么区别？
**A**: 
- **已出席**：人员到场参加了活动，但还未考核
- **已合格**：人员不仅出席，还通过了考核，可以拿工资

### Q2: 什么时候应该使用"已合格"状态？
**A**: 
- 活动结束后，对出席人员进行考核
- 考核通过的人员设置为"已合格"
- 作为发薪的依据

### Q3: 可以直接从"已确认"改为"已合格"吗？
**A**: 
- 技术上可以，但不建议
- 建议按流程：已确认 → 已出席 → 已合格
- 保持状态流转的逻辑性

### Q4: 如果人员出席了但考核不合格怎么办？
**A**: 
- 保持"已出席"状态
- 或者根据业务需求设置其他状态
- 在备注中说明原因

### Q5: "已合格"人员一定会发薪吗？
**A**: 
- "已合格"表示符合发薪条件
- 实际发薪还需要看"发薪状态"字段
- 两个字段配合使用

### Q6: 批量修改状态时，可以批量设置为"已合格"吗？
**A**: 
- 可以，支持批量修改
- 适用于统一考核通过的情况
- 建议先筛选"已出席"人员再批量修改

### Q7: 导入人员时可以直接设置为"已合格"吗？
**A**: 
- 可以，在Excel的"参与状态"列填写"已合格"
- 但建议按实际流程设置
- 避免状态混乱

### Q8: 如何统计某活动的合格率？
**A**: 
1. 进入活动详情页面
2. 查看参与人员列表
3. 统计"已出席"和"已合格"人数
4. 计算：合格率 = 已合格 / 已出席

### Q9: "已合格"状态可以改回"已出席"吗？
**A**: 
- 可以，支持状态修改
- 如果发现考核有误，可以改回
- 建议在备注中说明修改原因

### Q10: 筛选"已合格"人员后可以导出吗？
**A**: 
- 可以，筛选后点击"导出"按钮
- 导出的Excel包含所有筛选结果
- 便于财务审核和存档

## 最佳实践

### 1. 标准化考核流程

**建议流程**：
```
活动前：待确认 → 已确认
活动中：已出席（签到）
活动后：考核 → 已合格（通过）或保持已出席（未通过）
发薪时：筛选"已合格" → 发薪 → 标记"已发薪"
```

### 2. 明确合格标准

**建议**：
- 制定书面的合格标准
- 不同活动类型可以有不同标准
- 标准要清晰、可量化
- 让参与人员提前知晓

### 3. 及时更新状态

**建议**：
- 活动结束后24小时内完成考核
- 考核结果及时更新到系统
- 避免积压和遗漏

### 4. 记录考核依据

**建议**：
- 在备注中记录考核结果
- 说明合格或不合格的原因
- 便于后续查询和申诉

### 5. 定期数据分析

**建议**：
- 每月统计合格率
- 分析不合格原因
- 优化考核标准和流程
