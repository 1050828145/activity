# 活动批量修改功能增强

## 更新内容

### 新增功能：批量修改活动类型

在原有的批量修改活动状态功能基础上，新增了批量修改活动类型的功能。

## 功能说明

### 1. 批量修改活动状态（原有功能）

**功能描述：**
- 可以同时修改多个活动的状态
- 支持的状态：待确认、已确认、进行中、已完成、已取消

### 2. 批量修改活动类型（新增功能）

**功能描述：**
- 可以同时修改多个活动的类型
- 从数据库中动态加载所有可用的活动类型
- 支持与状态同时修改

## 使用方法

### 操作步骤

1. **选择活动**
   - 在活动列表中勾选需要修改的活动
   - 可以选择一个或多个活动
   - 选中后会显示已选数量

2. **打开批量修改对话框**
   - 点击"批量修改"按钮
   - 按钮上会显示选中的活动数量，如"批量修改 (3)"

3. **选择要修改的字段**
   - **活动状态**（可选）：从下拉列表中选择新的状态
   - **活动类型**（可选）：从下拉列表中选择新的活动类型
   - 可以只修改其中一个字段，也可以同时修改两个字段
   - 不选择的字段将保持原值不变

4. **确认修改**
   - 点击"批量更新"按钮执行修改
   - 点击"取消"按钮放弃修改

5. **查看结果**
   - 修改成功后会显示成功提示
   - 活动列表会自动刷新显示最新数据

## 使用场景

### 场景1：统一修改活动类型

**需求**：将多个活动的类型从"培训"改为"会议"

**操作**：
1. 勾选需要修改的活动
2. 点击"批量修改"按钮
3. 在"活动类型"下拉框中选择"会议"
4. 不选择"活动状态"（保持原状态不变）
5. 点击"批量更新"

**结果**：
- 选中的活动类型全部更新为"会议"
- 其他字段（包括状态）保持不变

### 场景2：同时修改类型和状态

**需求**：将几个培训活动改为会议类型，并标记为已确认

**操作**：
1. 勾选需要修改的活动
2. 点击"批量修改"按钮
3. 在"活动状态"下拉框中选择"已确认"
4. 在"活动类型"下拉框中选择"会议"
5. 点击"批量更新"

**结果**：
- 选中的活动类型全部更新为"会议"
- 选中的活动状态全部更新为"已确认"
- 其他字段保持不变

### 场景3：只修改状态

**需求**：将多个活动标记为已完成

**操作**：
1. 勾选需要修改的活动
2. 点击"批量修改"按钮
3. 在"活动状态"下拉框中选择"已完成"
4. 不选择"活动类型"（保持原类型不变）
5. 点击"批量更新"

**结果**：
- 选中的活动状态全部更新为"已完成"
- 活动类型和其他字段保持不变

### 场景4：活动分类整理

**需求**：整理历史活动，将所有线下活动统一分类

**操作**：
1. 使用筛选功能找出所有线下活动
2. 全选这些活动
3. 点击"批量修改"按钮
4. 在"活动类型"下拉框中选择"线下活动"
5. 点击"批量更新"

**结果**：
- 所有选中的活动类型统一为"线下活动"
- 便于后续的分类统计和管理

- 支持同时修改状态和类型

### 2. 动态加载
- 活动类型从数据库动态加载
- 自动同步最新的活动类型列表
- 支持自定义活动类型

### 3. 批量处理
- 一次操作可以修改多个活动
- 提高工作效率
- 减少重复操作

### 4. 数据安全
- 修改前需要确认
- 支持取消操作
- 只修改选中的字段

### 5. 用户体验
- 清晰的操作提示
- 显示选中的活动数量
- 修改成功后自动刷新列表
- 友好的错误提示

## 注意事项

### 操作提示
- 至少需要选择一个活动才能进行批量修改
- 批量修改对话框中至少需要选择一个字段（状态或类型）
- 修改操作不可撤销，请谨慎操作

### 权限要求
- 需要登录后才能使用批量修改功能
- 未登录时会提示先登录

### 数据验证
- 活动类型必须是系统中已存在的类型
- 活动状态必须是预定义的状态之一

## 常见问题

### Q1: 为什么批量修改按钮是灰色的？
**A**: 需要先选择至少一个活动。勾选活动后，按钮会变为可用状态。

### Q2: 可以只修改活动类型不修改状态吗？
**A**: 可以。在批量修改对话框中，只选择活动类型，不选择活动状态即可。

### Q3: 批量修改会影响活动的其他信息吗？
**A**: 不会。批量修改只会更新您选择的字段（状态或类型），其他字段保持不变。

### Q4: 批量修改失败怎么办？
**A**: 
1. 检查网络连接是否正常
2. 确认是否已登录
3. 刷新页面后重试
4. 如果问题持续，请联系技术支持

### Q5: 可以批量修改其他字段吗？
**A**: 当前版本支持批量修改状态和类型。如需修改其他字段，请联系技术支持。

### Q6: 批量修改后可以撤销吗？
**A**: 批量修改操作不可撤销。如果误操作，需要手动修改回原值。建议在修改前确认选择的活动和修改内容。

### Q7: 活动类型列表是从哪里来的？
**A**: 活动类型列表从数据库动态加载，显示的是系统中所有可用的活动类型。可以在"活动类型管理"页面添加或修改活动类型。

## 技术实现

### 前端实现
- 使用React Hook Form进行表单管理
- 使用Zod进行数据验证
- 动态加载活动类型列表
- 过滤空值，只更新选中的字段

### 后端实现
- 使用Supabase批量更新API
- 支持部分字段更新
- 自动处理空字符串转null

### 数据流程
1. 用户选择活动
2. 打开批量修改对话框
3. 加载活动类型列表
4. 用户选择要修改的字段
5. 提交表单
6. 过滤空值
7. 调用API批量更新
8. 刷新活动列表
9. 显示成功提示
