# 领队招募分析 - 功能演示

## 功能概览

本次更新为"领队招募情况分析"页面添加了两个重要功能：
1. **领队选择功能** - 灵活选择要分析的领队
2. **PDF导出功能** - 一键导出专业的分析报告

---

## 功能1：领队选择

### 界面展示

```
┌─────────────────────────────────────────────────────────┐
│  领队招募情况分析                    [选择领队 3] [导出PDF] │
└─────────────────────────────────────────────────────────┘
```

点击"选择领队"按钮后：

```
┌──────────────────────────────┐
│ 选择要分析的领队      [全选]  │
├──────────────────────────────┤
│ ☑ 张三                        │
│ ☑ 李四                        │
│ ☑ 王五                        │
│ ☐ 赵六                        │
│ ☐ 孙七                        │
├──────────────────────────────┤
│      [取消]      [确认]       │
└──────────────────────────────┘
```

### 操作流程

1. **打开选择面板**
   - 点击页面右上角的"选择领队"按钮
   - 按钮上的数字徽章显示当前选中的领队数量

2. **选择领队**
   - 勾选或取消勾选领队复选框
   - 点击"全选"快速选中所有领队
   - 点击"取消全选"快速取消所有选择
   - 可以多次调整选择，不会立即触发数据更新

3. **确认或取消**
   - 点击"确认"按钮应用选择并更新数据
   - 点击"取消"按钮放弃本次修改，恢复到之前的选择
   - 确认按钮在未选择任何领队时会被禁用

4. **查看结果**
   - 确认后，页面自动更新并显示成功提示
   - 统计卡片显示选中领队的汇总数据
   - 图表只显示选中领队的数据
   - 表格只列出选中领队的详情

### 使用场景

#### 场景A：对比特定领队
**需求**：想对比张三和李四两个领队的招募情况

**操作**：
1. 点击"选择领队"
2. 点击"取消全选"
3. 只勾选"张三"和"李四"
4. 点击"确认"按钮
5. 查看更新后的对比数据

**结果**：
- 统计卡片显示这两人的总和
- 柱状图只显示这两人的对比
- 饼图显示这两人的活动类型分布

#### 场景B：排除某个领队
**需求**：想查看除了王五之外的所有领队数据

**操作**：
1. 点击"选择领队"
2. 取消勾选"王五"
3. 其他领队保持选中状态
4. 点击"确认"按钮

**结果**：
- 所有数据中不包含王五的数据

#### 场景C：单个领队分析
**需求**：深入分析张三的招募情况

**操作**：
1. 点击"选择领队"
2. 点击"取消全选"
3. 只勾选"张三"
4. 点击"确认"按钮
5. 点击表格中的"查看详情"按钮

**结果**：
- 查看张三的完整招募数据
- 包括招募的每个人员的详细信息

## 功能2：PDF导出

### 导出内容

导出的PDF包含以下内容：

```
┌─────────────────────────────────────┐
│  领队招募情况分析                    │
├─────────────────────────────────────┤
│  ┌─────────┐ ┌─────────┐            │
│  │活跃领队数│ │总招募人数│  ...      │
│  │   5     │ │   120   │            │
│  └─────────┘ └─────────┘            │
├─────────────────────────────────────┤
│  [领队招募人数对比 - 柱状图]         │
│  [活动类型分布 - 饼图]               │
├─────────────────────────────────────┤
│  领队招募详情表格                    │
│  ┌────┬────┬────┬────┬────┐        │
│  │姓名│人数│活动│出勤│类型│         │
│  ├────┼────┼────┼────┼────┤        │
│  │张三│ 25 │ 10 │95% │... │         │
│  │李四│ 30 │ 12 │92% │... │         │
│  └────┴────┴────┴────┴────┘        │
└─────────────────────────────────────┘
```

### 操作流程

1. **准备数据**
   - 选择要分析的领队（可选，默认全选）
   - 确认页面显示的数据正确

2. **开始导出**
   - 点击"导出PDF"按钮
   - 看到提示："正在生成PDF，请稍候..."
   - 按钮显示"导出中..."

3. **完成导出**
   - 看到提示："PDF导出成功！"
   - PDF文件自动下载到本地
   - 文件名：`领队招募分析_2026/1/29.pdf`

### 导出质量

- **高清晰度**：使用2倍缩放，确保图表和文字清晰
- **完整内容**：包含所有统计卡片、图表和表格
- **自动分页**：内容超过一页时自动分页，不会截断
- **专业格式**：A4纸张大小，适合打印和存档

### 使用场景

#### 场景A：月度报告
**需求**：每月生成一份完整的招募情况报告

**操作**：
1. 确保所有领队都被选中（默认状态）
2. 点击"导出PDF"
3. 保存文件，重命名为"2026年1月招募报告.pdf"

**用途**：
- 存档备份
- 发送给管理层
- 团队会议使用

#### 场景B：个人报告
**需求**：为张三生成个人招募报告

**操作**：
1. 点击"选择领队"，只选择"张三"
2. 点击"导出PDF"
3. 保存文件，重命名为"张三_招募报告.pdf"

**用途**：
- 绩效评估
- 个人反馈
- 奖励依据

#### 场景C：对比分析
**需求**：对比分析几个优秀领队的数据

**操作**：
1. 选择表现优秀的几个领队
2. 点击"导出PDF"
3. 保存文件，重命名为"优秀领队对比分析.pdf"

**用途**：
- 经验总结
- 培训材料
- 标杆学习

## 技术特点

### 1. 优化的交互体验
- 勾选领队时不会立即触发数据加载，避免频繁请求
- 点击"确认"按钮后才更新数据，减少不必要的API调用
- 点击"取消"按钮可以放弃修改，恢复到之前的选择
- 无需刷新页面，流畅的用户体验

### 2. 智能处理
- 自动计算选中领队的汇总数据
- 自动调整图表显示
- 自动过滤表格数据
- 未选择任何领队时自动禁用确认按钮

### 3. 高质量输出
- PDF使用高分辨率图片
- 保持原有的颜色和样式
- 自动处理长内容分页

### 4. 友好提示
- 清晰的操作反馈（确认后显示成功提示）
- 详细的错误说明
- 贴心的使用指引

## 注意事项

### 导出限制
- ✅ 至少选择一个领队才能导出
- ✅ 导出过程中请勿关闭页面
- ✅ 内容较多时生成时间较长

### 浏览器兼容
- ✅ Chrome（推荐）
- ✅ Edge
- ✅ Firefox
- ⚠️ Safari（可能需要手动允许下载）

### 文件大小
- 选择的领队越多，PDF文件越大
- 一般情况下：5-10个领队约1-2MB
- 建议：单次导出不超过20个领队

## 常见问题

### Q1: 为什么导出按钮是灰色的？
**A**: 没有选择任何领队。请至少选择一个领队。

### Q2: PDF在哪里？
**A**: 检查浏览器的下载文件夹，通常在：
- Windows: `C:\Users\用户名\Downloads\`
- Mac: `~/Downloads/`

### Q3: 导出失败怎么办？
**A**: 
1. 检查浏览器是否阻止了下载
2. 尝试减少选择的领队数量
3. 刷新页面后重试

### Q4: 可以自定义PDF内容吗？
**A**: 当前版本导出固定内容。如需自定义，请联系技术支持。

### Q5: 选择领队后数据不更新？
**A**: 请稍等片刻，系统正在加载。如果长时间无响应，请刷新页面。
