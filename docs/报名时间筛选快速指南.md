# 报名时间筛选 - 快速使用指南

## 一分钟上手

### 基本操作（3步）

```
1. 点击"筛选"按钮 → 2. 设置日期范围 → 3. 查看结果
```

## 常用场景速查

### 场景1：查看今天的报名
```
开始日期：今天
结束日期：今天
```

### 场景2：查看本周的报名
```
开始日期：本周一
结束日期：不设置（默认到今天）
```

### 场景3：查看本月的报名
```
开始日期：本月1号
结束日期：本月最后一天
```

### 场景4：查看最近7天的报名
```
开始日期：7天前
结束日期：不设置（默认到今天）
```

### 场景5：查看某个月的报名
```
开始日期：该月1号（如2026-01-01）
结束日期：该月最后一天（如2026-01-31）
```

## 快捷技巧

### 技巧1：只看最近的报名
- 只设置开始日期
- 不设置结束日期
- 自动显示从开始日期到今天的所有报名

### 技巧2：只看历史报名
- 不设置开始日期
- 只设置结束日期
- 显示从最早到结束日期的所有报名

### 技巧3：组合筛选更精准
```
时间范围 + 活动名称 = 查看某活动在某时段的报名
时间范围 + 介绍人 = 查看某领队在某时段的招募
时间范围 + 状态 = 查看某时段内特定状态的报名
```

### 技巧4：快速清除
- 点击"清除筛选"按钮
- 所有筛选条件（包括时间）一键清除

## 实用示例

### 示例1：月度统计
**目标**：统计上个月的报名情况

**操作**：
```
1. 点击"筛选"
2. 开始日期：上月1号
3. 结束日期：上月最后一天
4. 点击"导出"保存数据
```

### 示例2：领队绩效
**目标**：查看张三本月招募了多少人

**操作**：
```
1. 点击"筛选"
2. 介绍人：选择"张三"
3. 开始日期：本月1号
4. 结束日期：今天
```

### 示例3：活动报名追踪
**目标**：查看"年会活动"的报名时间分布

**操作**：
```
1. 点击"筛选"
2. 活动名称：输入"年会"
3. 设置不同时间段查看各阶段报名数
```

## 注意事项

### ✅ 正确用法
- 开始日期 ≤ 结束日期
- 先选开始日期，再选结束日期
- 可以只设置一个日期

### ❌ 常见错误
- 开始日期 > 结束日期（不会显示结果）
- 选择未来日期（没有数据）
- 忘记清除旧的筛选条件

## 常见问题速查

| 问题 | 解决方法 |
|------|---------|
| 没有显示数据 | 检查日期范围是否正确 |
| 数据太多 | 缩小时间范围或添加其他筛选条件 |
| 想看今天的 | 开始和结束都设为今天 |
| 想看本周的 | 开始设为本周一，结束不设置 |
| 如何清除 | 点击"清除筛选"按钮 |

## 组合筛选示例

### 组合1：时间 + 状态
```
用途：查看本月待确认的报名
设置：
- 开始日期：本月1号
- 参与状态：待确认
```

### 组合2：时间 + 领队
```
用途：查看张三上周的招募情况
设置：
- 开始日期：上周一

- 介绍人：张三
```

### 组合3：时间 + 活动
```
用途：查看年会活动的报名时间分布
设置：
- 活动名称：年会
- 分别设置不同时间段查看
```

### 组合4：时间 + 发薪状态
```
用途：查看本月已发薪的人员
设置：
- 开始日期：本月1号
- 发薪状态：已发薪
```

## 数据导出

### 导出筛选后的数据
1. 设置时间范围和其他筛选条件
2. 点击"导出"按钮
3. 获得Excel文件，包含筛选后的所有记录

### 导出用途
- 月度报告
- 数据分析
- 备份存档
- 分享给他人

## 最佳实践

### 1. 定期统计
- 每周统计一次新增报名
- 每月导出数据存档
- 建立报名趋势分析

### 2. 及时处理
- 每天查看当天的新报名
- 筛选"待确认"状态及时处理
- 避免遗漏

### 3. 绩效评估
- 按月统计各领队的招募情况
- 对比不同时期的数据
- 作为考核依据

### 4. 活动分析
- 分析活动报名的时间分布
- 找出报名高峰期
- 优化宣传策略

### 5. 数据备份
- 定期导出历史数据
- 按月或按季度存档
- 便于长期分析
