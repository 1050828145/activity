# 参与人员管理 - 报名时间范围筛选功能

## 功能概述

在参与人员管理页面新增报名时间范围筛选功能，方便用户快速查看特定时间段内新增的报名人员，提升数据查询和统计的效率。

## 功能说明

### 新增筛选条件

**报名时间范围筛选**
- **报名开始日期**：筛选此日期（含）之后报名的人员
- **报名结束日期**：筛选此日期（含）之前报名的人员
- 可以单独使用开始日期或结束日期
- 也可以同时使用两个日期，筛选特定时间段内的报名

### 筛选逻辑

1. **只设置开始日期**
   - 显示从开始日期（含）至今的所有报名人员
   - 例如：设置开始日期为2026-01-01，显示2026年1月1日及之后的报名

2. **只设置结束日期**
   - 显示从最早到结束日期（含）的所有报名人员
   - 例如：设置结束日期为2026-01-31，显示2026年1月31日及之前的报名

3. **同时设置开始和结束日期**
   - 显示在这个时间范围内的报名人员
   - 例如：开始日期2026-01-01，结束日期2026-01-31，显示2026年1月的所有报名

### 时间精度

- **开始日期**：从当天的00:00:00开始
- **结束日期**：到当天的23:59:59结束
- 确保包含选定日期的完整一天

## 使用方法

### 基本操作

1. **打开筛选面板**
   - 点击页面上方的"筛选"按钮
   - 筛选面板会展开显示所有筛选条件

2. **设置时间范围**
   - 在"报名开始日期"字段选择开始日期
   - 在"报名结束日期"字段选择结束日期
   - 可以只设置其中一个，也可以两个都设置

3. **查看结果**
   - 设置日期后，列表会自动更新
   - 只显示符合时间范围的报名人员

4. **清除筛选**
   - 点击"清除筛选"按钮
   - 所有筛选条件（包括时间范围）会被清除
   - 列表恢复显示所有人员

### 组合筛选

时间范围筛选可以与其他筛选条件组合使用：

- **人员姓名** + 时间范围：查找特定人员在某时间段的报名
- **介绍人** + 时间范围：查看某领队在某时间段招募的人员
- **活动名称** + 时间范围：查看某活动在某时间段的报名情况
- **参与状态** + 时间范围：查看某时间段内特定状态的报名
- **发薪状态** + 时间范围：查看某时间段内的发薪情况

## 使用场景

### 场景1：查看本月新增报名

**需求**：查看本月有多少人报名参加活动

**操作**：
1. 点击"筛选"按钮
2. 设置"报名开始日期"为本月1号（如2026-01-01）
3. 设置"报名结束日期"为本月最后一天（如2026-01-31）
4. 查看筛选结果

**结果**：
- 显示本月所有报名人员
- 可以看到总人数、参与的活动等信息
- 便于月度统计和分析

### 场景2：查看最近一周的报名

**需求**：查看最近一周有哪些新报名

**操作**：
1. 点击"筛选"按钮
2. 设置"报名开始日期"为7天前的日期
3. 不设置结束日期（默认到今天）
4. 查看筛选结果

**结果**：
- 显示最近7天的所有报名
- 及时了解最新的报名动态
- 便于跟进和处理

### 场景3：统计某活动的报名时间分布

**需求**：查看某个活动在不同时间段的报名情况

**操作**：
1. 点击"筛选"按钮
2. 在"活动名称"中输入活动名称
3. 设置不同的时间范围查看各时段报名数量
   - 第一周：开始日期=活动发布日，结束日期=发布后7天
   - 第二周：开始日期=发布后8天，结束日期=发布后14天
   - 以此类推

**结果**：
- 了解活动报名的时间分布
- 分析报名高峰期
- 优化后续活动的宣传时机

### 场景4：查看某领队的招募效率

**需求**：查看某领队在某时间段招募了多少人

**操作**：
1. 点击"筛选"按钮
2. 在"介绍人(领队)"中选择领队
3. 设置时间范围（如本月）
4. 查看筛选结果

**结果**：
- 显示该领队在指定时间段招募的所有人员
- 评估领队的招募效率
- 作为绩效考核的依据

### 场景5：查看历史报名数据

**需求**：查看去年同期的报名情况，用于对比分析

**操作**：
1. 点击"筛选"按钮
2. 设置"报名开始日期"为去年同期开始日期
3. 设置"报名结束日期"为去年同期结束日期
4. 查看筛选结果并导出数据

**结果**：
- 获取历史同期数据
- 进行同比分析
- 发现趋势和规律

### 场景6：筛选待处理的新报名

**需求**：查看最近3天内状态为"待确认"的报名

**操作**：
1. 点击"筛选"按钮
2. 设置"报名开始日期"为3天前
3. 在"参与状态"中选择"待确认"
4. 查看筛选结果

**结果**：
- 显示最近3天内待确认的报名
- 及时处理新报名
- 避免遗漏

## 注意事项

### 日期选择
- 开始日期应早于或等于结束日期
- 如果开始日期晚于结束日期，可能不会显示任何结果
- 建议先选择开始日期，再选择结束日期

### 数据范围
- 只能筛选已有的报名数据
- 未来日期不会有数据
- 系统上线前的数据可能没有准确的报名时间

### 性能考虑
- 时间范围越大，数据量可能越多
- 建议配合其他筛选条件使用
- 大量数据时可能需要稍等片刻

### 导出功能
- 筛选后的数据可以导出
- 导出的Excel文件只包含筛选后的记录
- 便于进一步分析和报告

## 常见问题

### Q1: 为什么设置了日期后没有显示任何数据？
**A**: 可能的原因：
1. 选择的时间范围内确实没有报名数据
2. 开始日期晚于结束日期
3. 与其他筛选条件组合后没有符合的记录

**解决方法**：
- 检查日期设置是否正确
- 尝试扩大时间范围
- 清除其他筛选条件后再试

### Q2: 如何查看今天的报名？
**A**: 
1. 设置"报名开始日期"为今天
2. 设置"报名结束日期"为今天
3. 或者只设置"报名开始日期"为今天

### Q3: 如何查看本周的报名？
**A**: 
1. 设置"报名开始日期"为本周一
2. 不设置结束日期（默认到今天）
3. 或者设置"报名结束日期"为本周日

### Q4: 可以查看某个月的报名吗？
**A**: 可以。
1. 设置"报名开始日期"为该月1号
2. 设置"报名结束日期"为该月最后一天
3. 例如：2026-01-01 到 2026-01-31

### Q5: 时间筛选会影响导出功能吗？
**A**: 会。导出功能会导出当前筛选后的数据，包括时间范围筛选的结果。

### Q6: 如何快速清除时间筛选？
**A**: 点击"清除筛选"按钮，会清除所有筛选条件，包括时间范围。

### Q7: 报名时间是指什么时间？
**A**: 报名时间是指参与记录创建的时间（created_at字段），即人员被添加到活动的时间。
