# 仪表盘今日新增统计功能说明

## 更新概述

为仪表盘添加"今日新增"统计部分，显示今天新增的活动、人员、领队和参与记录数量，帮助用户快速了解当天的数据变化情况。

## 一、功能说明

### 1.1 今日新增统计定义

**今日新增统计**：统计今天（00:00:00 - 23:59:59）新创建的数据记录数量。

**统计维度**：
1. **新增活动**：今天新创建的活动数量
2. **新增人员**：今天新录入的人员数量
3. **新增领队**：今天新录入的领队数量
4. **新增参与记录**：今天新增的参与记录数量

**统计依据**：
- 基于数据表的 `created_at` 字段
- 时间范围：今天的 00:00:00 到 23:59:59
- 实时更新，每次刷新仪表盘时重新统计

### 1.2 实现效果

#### 仪表盘布局
```
仪表盘
├── 总体统计（第一行）
│   ├── 活动总数
│   ├── 人员总数
│   ├── 领队总数
│   ├── 正在进行
│   ├── 即将进行
│   ├── 即将结束
│   └── 待发薪人数
└── 今日新增（第二行）
    ├── 新增活动
    ├── 新增人员
    ├── 新增领队
    └── 新增参与记录
```

#### 统计卡片样式
- 浅蓝色背景（bg-primary/5）
- 蓝色边框（border-primary/30）
- 图标：使用带"+"的图标（CalendarPlus、UserPlus、UserCog、Plus）
- 标题：新增活动、新增人员、新增领队、新增参与记录
- 描述：今天新创建/新录入的XXX

## 四、技术实现

### 4.1 类型定义

```typescript
export interface Statistics {
  // 原有字段
  total_activities: number;
  total_persons: number;
  total_leaders: number;
  ongoing_activities: number;
  upcoming_activities: number;
  unpaid_participants: number;
  ending_soon_activities: number;
  
  // 新增字段
  today_new_activities: number;
  today_new_persons: number;
  today_new_leaders: number;
  today_new_participants: number;
}
```

### 4.2 API实现

```typescript
export async function getStatistics(): Promise<Statistics> {
  // 获取今天的日期范围
  const today = new Date().toISOString().split('T')[0];
  const todayStart = `${today}T00:00:00`;
  const todayEnd = `${today}T23:59:59`;

  // ... 原有统计逻辑

  // 获取今日新增活动数量
  const { count: todayNewActivities } = await supabase
    .from('activities')
    .select('*', { count: 'exact', head: true })
    .gte('created_at', todayStart)
    .lte('created_at', todayEnd);

  // 获取今日新增人员数量
  const { count: todayNewPersons } = await supabase
    .from('persons')
    .select('*', { count: 'exact', head: true })
    .gte('created_at', todayStart)
    .lte('created_at', todayEnd);

  // 获取今日新增领队数量
  const { count: todayNewLeaders } = await supabase
    .from('leaders')
    .select('*', { count: 'exact', head: true })
    .gte('created_at', todayStart)
    .lte('created_at', todayEnd);

  // 获取今日新增参与记录数量
  const { count: todayNewParticipants } = await supabase
    .from('activity_participants')
    .select('*', { count: 'exact', head: true })
    .gte('created_at', todayStart)
    .lte('created_at', todayEnd);

  return {
    // ... 原有返回值
    today_new_activities: todayNewActivities || 0,
    today_new_persons: todayNewPersons || 0,
    today_new_leaders: todayNewLeaders || 0,
    today_new_participants: todayNewParticipants || 0,
  };
}
```

**关键点**：
1. 使用 `toISOString().split('T')[0]` 获取今天的日期（YYYY-MM-DD格式）
2. 构造今天的开始时间（00:00:00）和结束时间（23:59:59）
3. 使用 `gte` 和 `lte` 过滤 `created_at` 字段
4. 使用 `count: 'exact', head: true` 只获取数量，不获取数据
