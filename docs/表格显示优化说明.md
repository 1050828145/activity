# 表格显示优化 - 倒序排列与高度控制

## 更新概述

对系统中所有表格和列表进行显示优化：
1. 所有数据按创建时间倒序排列（最新的在最前面）
2. 表格高度自动适应屏幕，最高占满屏幕并支持滚动

## 一、数据排序优化

### 1.1 排序规则

**统一规则**：所有表格和列表按 `created_at`（创建时间）倒序排列

**排序方式**：`order('created_at', { ascending: false })`

**优势**：
- 最新数据优先显示
- 符合用户使用习惯
- 便于查看最近操作
- 提高工作效率

## 二、表格高度控制

### 2.1 优化目标

- 表格高度自动适应屏幕
- 最高不超过屏幕高度
- 内容超出时自动显示滚动条
- 表头固定（部分表格）

### 2.2 实现方案

#### 方案1：固定最大高度
```css
max-h-[calc(100vh-280px)]
```

**说明**：
- `100vh`：视口高度（屏幕高度）
- `-280px`：减去页面头部、标题、按钮等固定元素的高度
- 表格内容区域最高占据剩余空间

**适用场景**：
- 参与人员管理页面
- 活动类型管理页面
- 用户管理页面

#### 方案2：更大的固定高度
```css
max-h-[calc(100vh-400px)]
```

**说明**：
- 适用于页面顶部元素较多的情况
- 如活动详情页面的参与人员表格

**适用场景**：
- 活动详情页面的参与人员表格

### 2.3 涉及的页面

#### 参与人员管理页面（Participations.tsx）
```typescript
// 修改前
<div className="rounded-md border border-border overflow-hidden">

// 修改后
<div className="rounded-md border border-border overflow-auto max-h-[calc(100vh-280px)]">
```

**效果**：
- 表格最高占据屏幕剩余空间
- 内容超出时垂直和水平滚动
- 13列数据可以完整显示

#### 活动详情页面（ActivityDetail.tsx）
```typescript
// 修改前
<div className="rounded-md border border-border overflow-x-auto max-w-full">

// 修改后
<div className="rounded-md border border-border overflow-auto max-w-full max-h-[calc(100vh-400px)]">
```

**效果**：
- 参与人员表格高度受限
- 支持垂直和水平滚动
- 8列数据可以完整显示

#### 活动类型管理页面（ActivityTypes.tsx）
```typescript
// 修改前

// 修改后

```

**效果**：
- 类型列表高度受限
- 内容超出时自动滚动
- 3列数据简洁清晰

#### 用户管理页面（Users.tsx）
```typescript
// 修改前

// 修改后
<div className="rounded-md border overflow-auto max-h-[calc(100vh-280px)]">
```

**效果**：
- 用户列表高度受限
- 内容超出时自动滚动
- 6列数据合理显示

### 2.4 滚动行为

#### 垂直滚动
- 当表格行数超过可视区域时，自动显示垂直滚动条
- 用户可以上下滚动查看所有数据
- 表头保持可见（部分表格）

#### 水平滚动
- 当表格列数较多，宽度超过屏幕时，自动显示水平滚动条
- 用户可以左右滚动查看所有列
- 重要列固定（如姓名、操作列）

#### 双向滚动
- 同时支持垂直和水平滚动
- 使用 `overflow-auto` 实现
- 只在需要时显示滚动条

## 五、技术实现

### 5.1 数据库查询

#### Supabase Order
```typescript
const { data, error } = await supabase
  .from('table_name')
  .select('*')
  .order('created_at', { ascending: false });
```

**参数说明**：
- `created_at`：排序字段
- `ascending: false`：倒序（最新的在前）

#### 性能优化
- 在 `created_at` 字段上创建索引
- 提高排序查询性能
- 减少数据库负载

### 5.2 CSS 实现

#### Tailwind CSS 类
```css
/* 最大高度 */
max-h-[calc(100vh-280px)]

/* 自动滚动 */
overflow-auto

/* 水平滚动 */
overflow-x-auto

/* 垂直滚动 */
overflow-y-auto
```

#### calc() 函数
```css
calc(100vh - 280px)
```

**说明**：
- `100vh`：视口高度
- `-280px`：减去固定元素高度
- 动态计算最大高度

### 5.3 响应式设计

#### 不同屏幕尺寸
```typescript
// 大屏幕（桌面）
max-h-[calc(100vh-280px)]

// 中屏幕（平板）
max-h-[calc(100vh-240px)]

// 小屏幕（手机）
max-h-[calc(100vh-200px)]
```

**未来优化**：根据屏幕尺寸动态调整高度
