## 错误提示设计原则

### 1. 三要素结构
每个错误提示应包含：
- **问题描述**：清晰说明发生了什么
- **解决方案**：告诉用户如何解决（用 💡 标识）
- **求助指引**：如果用户无法自行解决，应该联系谁

### 2. 用户语言
- ❌ 避免：技术术语、错误代码、堆栈信息
- ✅ 使用：通俗易懂的日常用语

### 3. 可操作性
- 提供具体的操作步骤
- 告知可能的原因
- 给出替代方案

### 4. 情感关怀
- 使用友好的语气
- 避免责怪用户
- 表达理解和支持

## 实现方式

### 1. 统一的错误处理工具
```typescript
// 使用 formatApiError 自动转换错误
toast.error(formatApiError(error, '活动列表'));
```

### 2. 预定义的消息模板
```typescript
// 使用预定义的友好消息
toast.error(userFriendlyMessages.operation.copyFailed);
toast.success(userFriendlyMessages.success.created('活动'));
```

### 3. 智能错误识别
系统会自动识别：
- 网络状态（离线、超时）
- HTTP状态码（401、403、404、500+）
- 数据库错误（唯一约束、外键约束）
- 并返回相应的友好提示

## 使用示例

### 基础用法
```typescript
try {
  await createActivity(data);
  toast.success(userFriendlyMessages.success.created('活动'));
} catch (error) {
  toast.error(formatApiError(error, '创建活动'));
}
```

### 自定义消息
```typescript
if (newActivities.length === 0) {
  toast.error(
    'Excel文件中没有有效数据，请检查文件格式是否正确。\n\n' +
    '💡 解决方法：请下载模板文件，按照模板格式填写数据后重新上传。'
  );
  return;
}
```

### 带解决方案的错误
```typescript
toast.error(
  '导出失败，请稍后重试。\n\n' +
  '💡 可能原因：浏览器阻止了文件下载。\n\n' +
  '💡 解决方法：请检查浏览器的下载设置，允许本网站下载文件。' +
  '如需帮助，请联系技术支持。'
);
```
