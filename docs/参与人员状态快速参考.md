# 参与人员状态 - 快速参考卡片

## 状态一览表

| 状态 | 颜色 | 含义 | 使用时机 |
|------|------|------|---------|
| 待确认 | 灰色 | 已报名，等待确认 | 人员刚报名时 |
| 已确认 | 蓝色 | 报名已确认 | 确认报名后 |
| 已出席 | 绿色 | 已参加活动 | 活动签到时 |
| **已合格** | **青色** | **已出席且考核通过** | **考核通过后** |
| 未出席 | 红色 | 未参加活动 | 活动结束后 |
| 已取消 | 红色 | 取消参与 | 人员取消时 |

## 状态流转图

```
报名 → 待确认 → 已确认 → 已出席 → 已合格 ✓
                              ↓
                            未出席 ✗
```

## 核心概念

### "已出席" vs "已合格"

| 对比项 | 已出席 | 已合格 |
|--------|--------|--------|
| 含义 | 到场参加 | 到场且考核通过 |
| 发薪 | 可能发薪 | 确定发薪 |
| 考核 | 未考核 | 已考核通过 |
| 使用 | 活动中 | 活动后 |

## 快速操作

### 单个修改
```
1. 找到人员 → 2. 点击编辑 → 3. 选择"已合格" → 4. 保存
```

### 批量修改
```
1. 勾选人员 → 2. 批量修改状态 → 3. 选择"已合格" → 4. 确认
```

### 筛选查询
```
1. 点击筛选 → 2. 参与状态选"已合格" → 3. 查看结果
```

## 典型场景

### 场景1：活动考核
```
活动结束 → 签到人员标记"已出席" → 考核 → 通过者改为"已合格"
```

### 场景2：发薪管理
```
筛选"已合格"人员 → 导出名单 → 财务审核 → 发薪 → 标记"已发薪"
```

### 场景3：绩效统计
```
统计"已出席"人数 → 统计"已合格"人数 → 计算合格率
```

## 数据统计公式

### 出席率
```
出席率 = (已出席 + 已合格) / (已确认 + 已出席 + 已合格 + 未出席)
```

### 合格率
```
合格率 = 已合格 / (已出席 + 已合格)
```

### 发薪人数
```
发薪人数 = 已合格人数（或根据业务需求包含已出席）
```

## 注意事项

### ✅ 推荐做法
- 按顺序设置状态
- 制定明确的合格标准
- 及时更新状态
- 在备注中记录考核依据

### ❌ 避免错误
- 跳过"已出席"直接设为"已合格"
- 没有考核就设为"已合格"
- 合格标准不明确
- 状态更新不及时

## 常见问题速查

| 问题 | 答案 |
|------|------|
| 什么时候用"已合格"？ | 活动结束考核通过后 |
| 与"已出席"有何区别？ | 已合格=已出席+考核通过 |
| 可以批量修改吗？ | 可以 |
| 可以筛选吗？ | 可以 |
| 可以导出吗？ | 可以 |
| 影响发薪吗？ | 是，作为发薪依据 |

## 最佳实践

### 1. 标准流程
```
活动前：待确认 → 已确认
活动中：已出席（签到）
活动后：已合格（考核通过）
发薪时：筛选"已合格" → 发薪
```

### 2. 考核标准
- 制定书面标准
- 清晰可量化
- 提前告知参与者

### 3. 状态管理
- 活动结束24小时内完成考核
- 及时更新状态
- 记录考核依据

### 4. 数据分析
- 每月统计合格率
- 分析不合格原因
- 优化考核流程

## 实用技巧

### 技巧1：快速筛选待发薪人员
```
筛选条件：
- 参与状态：已合格
- 发薪状态：未发薪
```

### 技巧2：统计领队招募质量
```
筛选条件：
- 介绍人：选择领队
- 时间范围：本月
- 统计：已出席和已合格人数
```

### 技巧3：活动质量评估
```
查看活动详情 → 统计各状态人数 → 计算出席率和合格率
```

### 技巧4：批量考核通过
```
筛选"已出席" → 勾选考核通过的人员 → 批量改为"已合格"
```
